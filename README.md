# StudyShelf 📚
### Campus Resource Explorer

StudyShelf is a student-powered academic resource platform designed to make sharing and accessing study materials easier. It provides a centralised space where students can explore academic notes and previous-year question papers based on their subjects, academic years, and resource types.

### ✨ Features
- **Resource Library:** Browse academic notes and previous-year question papers.
- **Search Functionality:** Search resources by title or subject.
- **Smart Filtering:** Filter resources by academic year and resource type.
- **Upload Resources:** Share study materials through an interactive upload form.
- **Form Validation:** Validates input fields and file size (maximum 5 MB).
- **Interactive Cards:** Expand and collapse resource details.
- **Delete Resources:** Remove resources from the displayed library.
- **Responsive Design:** Accessible across desktop and mobile devices.

### 🛠️ Technologies Used
- HTML5 – Structure
- CSS3 – Styling and layout
- JavaScript – Functionality and interactivity
- Bootstrap 5 – Responsive design

### ⚙️ How to Run
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

### 📝 Note
This is a front-end demonstration project. Sample resources are preloaded, and newly added resources are stored temporarily in the browser session. Uploaded files are not permanently stored and will be lost when the page is refreshed.

### 💡 Project Goal
To encourage collaborative learning by making academic resources easier to discover and share among students.
